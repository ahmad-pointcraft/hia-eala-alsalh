# Implementation Plan: Bootstrap & Cleanup — MUI Migration Phase 0

**Branch**: `001-bootstrap-cleanup` | **Date**: 2026-05-08 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `specs/001-bootstrap-cleanup/spec.md`

## Summary

Complete Phase 0 of the Tailwind CSS + shadcn/ui → MUI v7 migration for the Masjid Prayer Time Display app. This is a "clean slate" cleanup that removes all Tailwind, shadcn/ui, Radix UI, and ~48 unused dependencies from a Figma-exported codebase, switches the package manager from pnpm to Yarn Berry v4+, and establishes the MUI theme infrastructure (dark emerald/gold palette) that subsequent specs build upon. The app will intentionally not compile after this phase — Spec 002 handles component migration to MUI.

## Technical Context

**Language/Version**: TypeScript 5.8.3 (strict mode) on React 18.3.1
**Primary Dependencies**: @mui/material 7.3.5, @mui/icons-material 7.3.5, @emotion/react 11.14.0, @emotion/styled 11.14.1, motion 12.23.24, lucide-react 0.487.0, date-fns 3.6.0
**Storage**: N/A (client-side kiosk, no persistent storage in this spec)
**Testing**: `yarn build` for build verification; no test framework in this phase (Spec 004 adds tests)
**Target Platform**: Chromium-based browser in kiosk mode (24/7 display)
**Project Type**: Single-page web application (kiosk)
**Performance Goals**: < 500KB gzipped bundle; 60fps animations; 1 re-render/sec via single timer
**Constraints**: No Tailwind, no shadcn/ui, no Radix, no CSS files, no `any` types, offline-capable
**Scale/Scope**: Single-page app, ~15 components, 1 screen, kiosk-only
