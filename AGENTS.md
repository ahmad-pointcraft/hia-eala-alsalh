## Working Conventions (established in session; binding)

1. **Commit approval flow**: propose the commit message (short — title + a few bullets) and WAIT for explicit user approval before running `git commit`. Never commit unilaterally. One logical change per commit; `refactor:`/`fix:`/`feat:` prefixes per repo style.
2. **Commit messages**: no spec tracking IDs (no "Phase 1", "FR-xxx", "P1-x"). Short, descriptive, user-verifiable language.
3. **Code comments** (Article X): JSDoc on exported contracts/types; plain `//` or UPPERCASE section comments in implementation files. No verbose multi-line comment essays; no spec IDs in comments.
4. **MUI imports**: grouped named imports (`import { Box, Button } from '@mui/material'`), not per-path imports.
5. **Verification gate**: `yarn typecheck` after every phase; `yarn build` before committing feature work. No automated tests (project convention) — verify via typecheck + manual E2E.
6. **Architecture invariants** (established post-015): adapters are closure factories (no `this` anywhere in src/); all entity types are Zod-inferred (`z.infer`); forms are React Hook Form + `zodResolver`; admin feedback flows through `useToast` (ToastProvider); CRUD tabs compose `useCrudList` + `useCrudDialogs`.

## Key Design Decisions for 016 (binding — from the runbook's clarify section)

1. **Preview button**: sticky AppBar, primary, always visible; `window.open(displayUrl?masjid=id)`; **removes** the `/preview` stub route.
2. **AsyncState integration rule**: `ContentList`/`useCrudList` refactor to CONSUME `AsyncState` internally — ONE state pipeline per list; never wrap a list that renders its own states (no double skeletons). Images/Timings/Devices adopt the same primitives.
3. **Pagination** (Announcements/Events/Donations): MUI `TablePagination`, client-side, [10/25/50] default 10; page resets to 0 on create/delete/reorder; one shared `usePagination` hook. Devices stays unpaged (short list).
4. **ToastProvider is the toast system** — verify its Snackbars announce (aria-live polite; assertive for errors); do not regress the centralized `useToast` conventions during the async-state refactor.
5. **Images route = idle slideshow manager** (post Option-C): photos show on the display only when no active events; event images are event-attributes. Use accurate copy ("slideshow photos"), not event imagery language.
6. **Display app is untouched** by 016 (admin-only hardening). Realtime already works: admin edits reach a paired/previewed display in ~1s.
7. **Admin UI labels are English** (v1 convention); Article VIII bilingual applies to display content, not admin chrome.
